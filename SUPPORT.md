# Avenor Support

Use the [Avenor issue tracker](https://github.com/mdmeraj-dev/avenor/issues) for confirmed problems, improvement suggestions, and language-specific highlighting reports.

Before opening an issue:

1. Confirm the active Avenor theme.
2. Record your VS Code version and relevant language-extension version.
3. Note whether semantic highlighting is enabled.
4. Reproduce the behavior with the smallest practical code sample.
5. Use **Developer: Inspect Editor Tokens and Scopes** and include the reported scope when possible.

For source changes, run `npm test` before submitting a pull request. Theme appearance can vary with the active grammar and semantic-token provider, so those details are essential for a useful report.
