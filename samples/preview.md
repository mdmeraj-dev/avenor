# Avenor Visual Preview

> Controlled vibrancy should reveal structure without overwhelming ordinary code.

## Semantic landmarks

- **Keywords** establish language structure.
- *Comments and supporting syntax* remain calm.
- [Properties and links](https://code.visualstudio.com/) use a clear blue family.
- Constants such as `MAX_RETRIES = 3` receive a warm accent.

```typescript
interface Theme {
  readonly name: string;
  activate(): Promise<boolean>;
}
```
